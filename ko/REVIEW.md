# 한국어판 통합 검수 결과

검수일: 2026-11-01 · 검토자: Codex (`agent`)

대상은 본문 13장과 부속 문서 5종이다. 번역 commit `6e6cc39`와 그림 준비 commit `509323e`를 통합한 뒤 교정했다. 원문 기준은 `ba20b2f820926587d5ee20ce312b3789d63f795c`이다. 이 문서는 사람의 전수 교열 또는 FreeRTOS/AWS 공식 검수 기록이 아니다.

## 수정한 내용

- 원문과 달라진 fenced code block 18개를 복구했다. 이 중 17개는 내용 차이가 있었으며, 특히 C 문자열의 `\r\n`·`\t`가 실제 줄바꿈·탭으로 바뀐 항목을 원문 그대로 되돌렸다. 나머지 1개는 fence 들여쓰기 차이였다.
- `image54.png`의 잘못된 경로를 `image54.ko.png`로 고쳤고, 13장의 인터럽트 우선순위 그림도 준비된 한글화 asset으로 연결했다. 본문 그림 82개를 manifest와 대조했다.
- 영문으로 남은 캡션을 번역하고 그림·코드·예제·표의 참조 표기를 정리했다. 목차 설명이 다른 그림의 캡션을 가리키던 항목을 바로잡았다. 그림 alt와 한국어 캡션을 맞추고 캡션을 독립된 문단으로 분리했다.
- 본문 객체명과 첫 등장 풀이를 용어집에 맞추고, 반복된 영문 괄호·부자연스러운 조사·일부 명령형 어미를 정리했다. 사용자 선택인 한국어·영어 병기 제목을 유지했다.
- 4장의 TLS 설명에서 `out-of-band results`를 함수 반환값으로 잘못 옮긴 문장을 수정했다. task 핸들 설명에서 빠졌던 `xTaskCreateStatic()`의 반환값을 복원했다. 9장에서 여러 이벤트를 기다리는 동작을 여러 event group을 기다리는 것으로 읽히게 한 표현을 바로잡았다.
- 원문의 API 이름·참조 번호·단위·중복 절 번호 등은 [원문 대조 사항 15개](SOURCE_NOTES.md)에 기록하고 해당 본문에 옮긴이 주를 달았다. 코드 안의 원문 오기나 오래된 설명은 임의 수정하지 않았다.

## 남은 검토와 판본의 한계

파일 상태는 `source-checked`로 유지한다. 전체 문장의 사람 교열, 모든 수치·조건의 독립적인 전수 재검토, 예제 빌드·실행, 하드웨어 실행, PDF 제작·출력 검수는 수행하지 않았다. 공개 저장소의 첫 통합본이며 `release-ready` 판정을 내린 판본은 아니다.

코드의 byte 단위 보존을 위해 원문 코드 8.13에 있는 줄 끝 공백 1곳도 유지했다. `git diff --check`의 해당 지적은 원문과 동일함을 확인한 예외다.

원문 대조 사항 N03(SMP idle stack 단위)과 N07(mutex 그림의 semaphore 표현)은 원저자·해당 버전 확인이 남은 `check-against-source` 항목이다. N09(stack high-water mark)는 동봉 커널 구현과 원문 단위의 차이를 확인해 함께 표시했다. 사용 중인 커널 버전의 API·port와 책의 설명을 구분한다.
