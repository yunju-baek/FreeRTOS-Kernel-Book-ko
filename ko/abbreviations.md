### 약어 목록 (List of Abbreviations)

| 약어 (Abbreviation) | 의미 (Meaning) |
|------|---------------------------------------------|
| ADC  | 아날로그-디지털 변환기 (Analog to Digital Converter) |
| API  | 응용 프로그램 프로그래밍 인터페이스 (Application Programming Interface) |
| DMA  | 직접 메모리 접근 (Direct Memory Access) |
| FAQ  | 자주 묻는 질문 (Frequently Asked Question) |
| FIFO | 선입선출 (First In First Out) |
| HMI  | 인간-기계 인터페이스 (Human Machine Interface) |
| IDE  | 통합 개발 환경 (Integrated Development Environment) |
| IRQ  | 인터럽트 요청 (Interrupt Request) |
| ISR  | 인터럽트 서비스 루틴 (Interrupt Service Routine) |
| LCD  | 액정 디스플레이 (Liquid Crystal Display) |
| MCU  | 마이크로컨트롤러 (Microcontroller) |
| RMS  | 단조 비율 스케줄링 (Rate Monotonic Scheduling) |
| RTOS | 실시간 운영체제 (Real-time Operating System) |
| SIL  | 안전 무결성 수준 (Safety Integrity Level) |
| SPI  | 직렬 주변장치 인터페이스 (Serial Peripheral Interface) |
| TCB  | 태스크 제어 블록 (Task Control Block) |
| UART | 범용 비동기 송수신기 (Universal Asynchronous Receiver/Transmitter) |
